# Test images

## lincoln_portrait.jpg

A head-and-shoulders portrait of Abraham Lincoln, used by
`tests/test_face_detection.py` to check that the detector finds a face.

- **Subject:** Abraham Lincoln, frontal head-and-shoulders portrait.
- **Photographer:** Alexander Gardner (1821-1882), a photograph from 1865 held by
  the Library of Congress.
- **Source:** https://commons.wikimedia.org/wiki/File:Abraham_Lincoln_head_on_shoulders_photo_portrait.jpg
  (the full-size original is 2850 x 3742 pixels).
- **License:** public domain: the photograph is from 1865, long past any copyright term, and
  the Wikimedia Commons file is marked "Public domain". Attribution is not
  required; the source above is recorded for provenance.
- **Changes:** downscaled to 300 pixels wide with OpenCV (INTER_AREA) and
  re-encoded as JPEG at quality 90. No other edits.
- **SHA-256 of this file:** `0a50eb57edefda08cf0853132864cd06b33bcde5daa8f4f747fb9149021390ee`
